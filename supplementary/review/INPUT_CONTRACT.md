# External input contract

No benchmark input files are included. Prepare your own inputs outside this archive.

The program controller accepts a run directory containing:

```text
run/
  manifest.json
  private_inputs/
    example/
      source.py
      candidate.py
      task.json
  private_references/
    example/
      101/measurement.json
      202/measurement.json
      303/measurement.json
```

Use the top-level repair settings from `configs/program_comparison.json` in `manifest.json`. Add a `tasks` list with a record containing `anonymous_id: "example"` and the applicable `input_form`. Set `runtime` to `mindspore`. The contract must declare the public interfaces and model variant needed by `evaluation/native/measure.py`, `seed: 101`, and `evaluation.final_seeds: [101, 202, 303]`.

Each reference file follows the native measurement schema: `status`, `seed`, `schema`, and `values`. Candidate measurements additionally contain observed backend evidence. Numerical names distinguish forward values, gradients, parameter updates, and initial states. References are generated by source execution and remain outside the agent workspace. Preserve identical source/candidate inputs, initial values, dtypes, shapes, seeds, and thresholds across methods.

The controller creates `conditions/<task>/<method>/workspace` and refuses to overwrite an existing condition. Public production inputs consist of `source.py`, `candidate.py`, and `task.json`; scratch tests are writable. Source and contract hashes are checked after evaluation. Reference arrays are not copied into model observations.

Repository measurement workers accept external source/target repositories and initialization JSON with their command-line arguments. The time-series and two-tower comparison predicates retain their original tolerances. `repository/orchestration.py` exposes `run(repository, method, root, evaluator_factory, adapter_factory=None)`; its prepared root contains `source/`, `task.json`, `manifest.json`, `freeze.json`, and `translation/target` with `translation/result.json`. The manifest supplies source hashes and the task hash; translation receipts supply initial target hashes, file states, and usage. The caller validates its frozen external inputs before dispatch. The evaluator factory supplies `tool(request)` and `final()`; the latter returns `accepted` and `observation`. A baseline adapter factory is required when the method is not `ladim`. The source repositories, preprocessed benchmark fixtures, and original repository tests are not distributed. The language worker consumes a prepared public training fixture; preparing that fixture and reproducing the cross-language paired benchmark require the withheld reference data.

Execution failure leaves unavailable measurements absent or null. It must not be represented by zero discrepancy or a passing numerical check. Use the final checkpoint at the declared submission budget, including regressions, and retain unsuccessful attempts in the denominator and cost accounting.
