# 论文意见清单

本文件是持续维护的唯一主清单。阅读论文发现问题、收到用户新意见、讨论形成新决定、完成修改时，都在这里更新。已落实的意见继续保留，每次修改后重新检查是否回退。日期版方案与执行记录提供历史依据，不替代本清单。

## 使用与更新规则

1. **边读边记。** 新意见分配固定 ID，记录来源、要解决的问题、涉及位置和验收条件。用户意见与代理建议分别标明；代理提出的改法不自动成为用户要求。
2. **修改前核对。** 阅读全部有效意见，检查当前 Git 状态与差异，确定本轮涉及的 ID 和具体方案。冲突时以用户最新明确意见或最新明确确认的方案为准，记录旧意见、后续决定及当前采用项。按原意见提出或最后确认的时间判断，不因旧意见重新粘贴而自动覆盖后来决定；代理未获确认的建议不能覆盖用户意见。用户要求先看方案时，完成检查和方案后再等用户审阅。
3. **修改后全表复核。** 对本轮涉及项逐项核验，同时重新检查其他有效意见，包括已经落实的条目。核对正文、摘要、结论、算法、图表标题、表注、生成脚本及附录之间的一致性。未检查的项目不能沿用旧检查日期或自动写成通过。
4. **保留历史。** 意见不因已完成而删除。后续调整保留原要求，并指向新决定；发现回退时重开原 ID。记录实际改动、检查结果和核验版本。检查时发现的新问题加入同一清单。
5. **按实际范围验证。** 文字修改核对含义、数字、公式和引用；图表修改同步生成器及资产并做相应检查；论文修订后编译、检查 PDF、刷新固定基线逐词比较。只记录本轮实际执行的检查，不把先前的编译或测试写成本轮执行。

状态含义：**待版面复核**表示本轮检查了源文件，未重新渲染；上轮视觉结论保留其原日期。**重新审核**表示发现旧验收不足，已重开问题。**已落实**表示当前核验版本满足要求；**部分落实**表示有明确缺口；**未落实**表示尚未满足；**回退**表示旧稿已落实而当前丢失；**后续调整**表示按后来的用户决定采用另一安排；**待审核**表示建议已提出、尚未修改；**已批准待执行**表示已有用户授权、实际修改尚未完成；**持续约束**表示每轮均要执行的要求。后续调整和持续约束仍在每轮检查范围内。
