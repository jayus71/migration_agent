# 新实验结果与论文修改决定

JAX 正式比较和 Repair Dependency Graph Planning（修复依赖图规划）消融均已完成，原始费用、冻结输入及最终结果通过审计。两个接管子代理使用 `gpt-6-astra`、`high`，承接原先已经启动的运行，未重复初译、完整方法或失败条件。

论文修改方案已按完整结果更新，见[论文内容与行文修改方案](paper-clarity-and-ablation-plan-20260922.md)。本轮交付方案与结果记录，论文正文和用户负责的方法图尚未应用修改。

## JAX：两项修复任务的结果相同

十二个公开来源各初译一次，八个通过初始验收，两个返回空正文，两个非空失败候选进入四方法修复比较。四方法均修复时间序列、未通过 ResNet。

| 方法 | 修复接受 | 修复调用 | 修复 token |
|---|---:|---:|---:|
| LaDiM | 1/2 | 35 | 1,840,066 |
| Direct repair | 1/2 | 28 | 760,935 |
| MatchFixAgent | 1/2 | 23 | 258,914 |
| SWE-agent | 1/2 | 66 | 1,013,532 |

时间序列修复恢复输入切片和输出拼接形状。ResNet 中，LaDiM、Direct repair 和 SWE-agent 将截断代码修复为可执行程序，最终实现均通过第一步全部数组检查，在第二或第三步出现梯度、更新等差异。MatchFixAgent 在原生语法分析时因截断候选提前终止，数值测量为 n/a，四次调用费用保留。

这组结果提供原生 JAX 迁移与多步训练验收的案例，但两个修复任务没有达到扩大修复比较规模的目标。论文保留 Generalization Across Frameworks 标题，将重点放在实际后端适用范围和多步检查发现的偏离；四方法完整结果与停止原因放附录。LaDiM 在这组任务中没有接受数或 token 优势。MatchFixAgent 的较低费用同时包含解析早退，需与停止原因一起解释。

共同初译共 139,724 token，整轮正式实验实际为 164 次调用、4,013,171 token，包括全部失败费用。跨方法汇总实际开销时共同初译只计一次。开发实验费用独立保留。

24 项最终三种子判定复现；独立检查确认 152 次修复调用和 12 次初译费用一致，6 条源轨迹的 1,908 个数组与参考逐值相同，6,042 个目标数组的验收判定独立重算一致。完整元数据归档已采集并核对哈希，5.20 GB 数组留在远端并有逐文件清单。详见[JAX 完整报告](jax-expansion-20260922.md)和[结果及审计](../output/jax-expansion-20260922/formal/formal_report.md)。

## 修复依赖图规划：费用下降，完整接受数相同

本轮仅新增两个关闭规划的运行。完整方法复用 Repository Structural Analysis（仓库结构分析）消融的原始结果，来源和非缓存证据字节均核对一致。

| 仓库 | 完整方法 | 关闭修复依赖图规划 | 关闭规划后的 token 变化 |
|---|---|---|---:|
| 时间序列 | 69/69，30 次调用，2,126,900 token | 69/69，21 次调用，1,803,551 token | 减少 15.2% |
| 推荐 | 131/145，80 次调用，9,961,503 token | 130/145，69 次调用，9,213,723 token | 减少 7.5% |

表中均为端到端 token。两种条件各完整接受一个仓库。时间序列关闭规划后首次提交通过，完整方法第二次通过。推荐关闭规划的提交轨迹为 128→103→133→130，最终耗尽输出预算，结果采用最后一次的 130/145。完整条件为 n/a→122→131→131。首次完整条件的八个执行失败标志不属于 145 项协议检查；旧仓库结构分析报告中的相关说明已改为 n/a，与原始统计一致。

这两个仓库各条件运行一次。本轮完整条件的 token 均更高，完整接受数相同；推荐的完整条件最终多通过一项，后续提交也保留了已获得的覆盖。论文按这些具体差异介绍规划的作用，方法贡献以训练行为诊断与证据交接为重点。实际耗时还受 CPU 放置和工具轨迹差异影响，token 与耗时分别报告。

新增费用为 90 次调用、10,485,245 token，未知 usage 为零。146 项最终审计、20 项机制测试及一项费用分账测试通过，200 组新增与复用调用证据逐一核对。完整归档已采集并核对哈希。详见[规划消融报告](work-unit-planning-ablation-20260922.md)和[证据索引](../data/audits/work-unit-planning-ablation-20260922/README.md)。

## 论文如何更明确地呈现已有贡献

摘要、引言与结论突出共同协议下已经得到的主要结果：MindSpore 接受 50/50，较 MatchFixAgent 节省 57.4% token；真实初译错误修复为 4/5，对照均为 0/5；训练信号消融从执行反馈的 4/16 上升到完整反馈的 16/16。Java/DJL 到 Python/PyTorch 和多入口时间序列仓库补充语言迁移与共享代码的应用范围。

全文使用 Repository Structural Analysis 和 Repair Dependency Graph Planning 两个正式名称。方法动机具体解释训练计算依赖如何指引调查，实验段明确方法、任务、指标和成本范围，图表标题及结论突出相应量化发现。独立仓库消融合并为一张六行表，每个仓库的完整方法只出现一次，保留不同组件和任务的全部效果方向。

方案已撤回将两个 JAX 修复任务作为扩大后主要修复比较的安排。若未来扩展，需在运行前固定更大的来源池、机制覆盖、初译预算和最小失败任务数；本轮没有启动后续实验。

本轮文档检查核对了提交结果、审计通过标志、成本计算、任务分母和相关链接。未修改 LaTeX 正文，因此本轮没有重新编译论文或刷新逐词比较页。应用方案时再按项目要求完成编译、PDF 检查和固定基线比较。
